DEEPANKAR-KUNJ NGO WEBSITE — POORI WEBSITE (ZIP)
================================================

Ye zip Deepankar-Kunj NGO ki poori website hai — saare latest changes ke saath:
loader mein teeno photos (Founder, Director, President cum Mentor), teeno posters
poori site par, press-cutting carousel, aur motto ki sahi spelling
"तमसो मा ज्योतिर्गमय" har jagah.

ZIP KE ANDAR KYA HAI
--------------------
- index.html   → website ki main file (naam pehle se hi index.html hai,
                 badalne ki zaroorat NAHI hai)
- assets/      → website ki saari 32 photos (ye folder index.html ke saath
                 hamesha rehna chahiye — photos isi se load hoti hain)

ZARURI BAAT
-----------
Sirf index.html akele chalane ya bhejne se photos load nahi hongi aur page
khaali dikh sakta hai. Website hamesha POORI leni hai — index.html + assets
folder ek saath. Isiliye ye zip banaya gaya hai: zip bhej dijiye, dusra banda
unzip karke poori site chala sakta hai.

NETLIFY PAR LIVE KARNE KE STEPS
-------------------------------
1. Zip ko unzip kijiye — ek folder milega: deepankar-kunj-website
2. Browser mein kholiye: https://app.netlify.com/drop
3. Unzip kiye hue FOLDER ko waisa ka waisa drag karke Netlify Drop par
   chhod dijiye (folder ke andar index.html aur assets dono hona chahiye)
4. Kuch seconds mein site live ho jayegi aur ek link milega

CHECK KAISE KAREIN KI NAYA VERSION HI HAI

  Director (डॉ. राजीव कुमार), President cum Mentor (डॉ. जितेन्द्र कुमार सिंह)
